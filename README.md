 # 🏕️ Restay (리스테이) - 숙박 및 캠핑 예약 플랫폼

> **Rest + Stay**: 복잡한 광고와 피로감을 줄이고, 휴식에 집중할 수 있는 사용자 친화적 숙박 예약 서비스입니다.

---

## 📌 Project Overview (프로젝트 개요)
* **팀명**: TEAM AWS 402
* **개발 기간**: 2026.08

---

## 🎯 Background & Purpose (개발 배경 및 목적)
* **사용자 친화적 UX/UI**: 필수 정보 중심의 깔끔한 숙소 탐색 및 직관적인 상세 페이지 제공
* **안정적인 예약 로직**: 날짜별 중복 예약을 방지하는 실시간 데이터 검증 및 예외 처리
* **통합 백오피스(Admin)**: 회원, 숙소, 예약, 문의 내역을 효율적으로 관리할 수 있는 Modal 기반 관리자 시스템 구축

---

## 🛠️ Tech Stack (기술 스택)
* **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5, Thymeleaf, AOS Animation
* **Backend**: Java, Spring Boot
* **Database**: MySQL
* **Tools**: IntelliJ IDEA, Git, SourceTree

## ✨ Key Features (주요 기능)

### 👤 User (사용자)
* **회원 관리**: 회원가입, 로그인, 개인정보 수정
* **숙소 탐색 및 상세 페이지**:
    * 객실별 상세 정보 및 이미지 캐러셀 슬라이드
    * Side Modal 기반 숙소 배치도 및 Kakao Map API 기반 위치 확인
* **예약 시스템**:
    * 체크인/체크아웃 날짜(FROM~TO) 선택에 따른 실시간 예약 가능 객실 조회
    * 인원수 및 총 금액 계산, 중복 예약 방지 로직 적용
* **고객센터**: Q&A 문의 작성/수정/삭제 및 답변 확인

### ⚙️ Admin (관리자)
* **회원 관리**: 전체 회원 리스트 조회, 정보 수정 및 신규 등록
* **숙소 및 예약 관리**: 전체 숙소 등록/수정, 예약 상태(예약중, 이용완료, 취소 등) 모니터링
* **Q&A 관리**: 고객 문의 확인 및 관리자 답변 등록/수정
